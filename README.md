# Fortune Web Solutions

Recreated from the Fortune Digital Pro concept with the new name **Fortune Web Solutions**.

## Colour system
- Alice Blue: `#ECF4F7`
- Charcoal: `#393F4B`
- Burgundy: `#910029`

## Included
Home, services, pricing, portfolio, quote requests, client portal demo, about, contact, mobile navigation and PWA support.

## GitHub Pages
Upload the files to the root of a GitHub repository, then enable Pages from `main` and `/ (root)`.

## Note
The client portal in this standalone version is a front-end demo using browser localStorage. A production version should use real authentication/database services such as Supabase.
